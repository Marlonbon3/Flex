# Flex WebApp — Pantalla de login

Proyecto mínimo con Vite + React que contiene la pantalla de `Login` solicitada.

Instrucciones rápidas:

1. Instala dependencias:

```bash
npm install
```

2. Ejecuta en modo desarrollo:

```bash
npm run dev
```

3. Coloca el logo de la empresa en `public/logo.png` (PNG o SVG).

Archivos clave:

- [src/components/Login.jsx](src/components/Login.jsx) — componente `Login`.
- [src/styles.css](src/styles.css) — estilos principales.
- [public/index.html](public/index.html) — raíz pública.
